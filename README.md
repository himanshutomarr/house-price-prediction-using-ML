# 🏠 House Price Prediction Using Machine Learning

An end-to-end Machine Learning project for predicting house prices using the House Prices dataset from Kaggle. The project covers data cleaning, exploratory data analysis, visualization, feature engineering, regression modeling, evaluation, and model comparison.

## 🎯 Objective

To develop and evaluate machine learning models for house price prediction while demonstrating practical skills in data analysis, preprocessing, visualization, feature engineering, and machine learning.

## 📊 Dataset

*Source:* [Kaggle – House Prices Dataset](https://www.kaggle.com/datasets/shree1992/housedata)

## 🛠️ Technologies Used

- Python 3.14
- Jupyter Notebook
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Microsoft Excel

## 🤖 Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## 📏 Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score

## 🏆 Results

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 139638.89 | 232409.25 | *0.6369* |
| Decision Tree | 149182.95 | 300352.01 | 0.3936 |
| Random Forest | *121307.27* | 319894.63 | 0.3121 |

*Final Model: Linear Regression*

Linear Regression achieved the highest R² Score and lowest RMSE among the evaluated models, so it was selected as the final model.
